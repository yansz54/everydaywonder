One sentence, at most 200 characters, that makes a small everyday moment strange and new.

> "The photocopier jams on the last page, every time, as if it reads the document and objects at the ending."

`main.ts` (Node 22, stdlib only) writes exactly that sentence to `/output/entry.txt`.
See [METHOD.md](METHOD.md) for the 30-candidate tournament that picked it.
